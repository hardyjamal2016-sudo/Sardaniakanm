سەردانیەکانم - وەشانی فینال Flutter Production

ناوی ئەپ: سەردانیەکانم
بەڕێوەبەر: سەرکەوت زەکی
PIN سەرەتایی: 1234

تایبەتمەندییەکان:
- PIN Login + Fingerprint/Face ID
- SQLite Offline Database
- زیادکردن/دەستکاریکردن/سڕینەوەی سەردان
- وێنەی سەردان بە کامێرا
- گەڕان بە ناو، ژمارە، یان چاوی بە کێ کەوتووە
- دۆخەکان: هات، چاوەڕێ، تەواوبوو، هەڵوەشاوە
- Dashboard و ڕاپۆرت
- Export بۆ PDF و Excel
- WhatsApp reminder
- ڕێکخستنی PIN و ناوی سکرتێر/بەڕێوەبەر
- Kurdish RTL UI

چۆنیەتی دروستکردنی APK:
1) Flutter و Android Studio دابمەزرێنە
2) پڕۆژەکە بکەرەوە
3) فەرمانەکان:
   flutter pub get
   flutter build apk --release

APK لەم شوێنە دەردەچێت:
build/app/outputs/flutter-apk/app-release.apk

تێبینی:
ئەم ژینگەیە Flutter SDK نییە، بۆیە APK compile ناکرێت لێرە، بەڵام پڕۆژەکە بۆ build کردن ئامادەیە.
